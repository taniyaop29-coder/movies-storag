--------------------------------------------------
1. Open https://my.telegram.org in your mobile or laptop browser.
2. Enter your Telegram phone number with country code (e.g., +919876543210).

4. Click on "API development tools".
5. If prompted to create an app, fill:
   - App title: NH Stream Host
   - Short name: nhstream
6. Copy your "App api_id" (numeric) and "App api_hash" (32-char string) into a note.

----------------------------------------------
1. Open @BotFather on Telegram and send /newbot
   - Display Name: NH Stream Bot

2. Create a New Telegram Channel:
   - Channel Name: NH Private Storage
   - Channel Type: PRIVATE (Strictly Private)
   - Go to Channel Settings -> Administrators -> Add Bot (@NHStreamBot) as Admin.
   - Make sure "Post Messages" and "Read" permissions are ON.
3. Get your numeric BIN_CHANNEL ID:
   - Send any test text message inside your Private Channel.
   - Forward that message to @userinfobot or @RawDataBot on Telegram.
   - Copy the Chat ID including the -100 prefix (Example: -1002198475612).
